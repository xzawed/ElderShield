# ElderShield 개인정보처리방침 (초안)

**시행일:** 2026-11-20  
**운영자:** ElderShield 저장소 관리자 (`xzawed`)  
**적용:** ElderShield Android 앱 및 연동 백엔드(가족/관리자 배포)

본 문서는 Google Play 등 스토어 등록용 **초안**입니다. 상용·다가족 서비스로 확대 시 법률 검토 후 개정하세요.

## 1. 수집하는 정보

| 구분 | 내용 | 목적 |
|------|------|------|
| 기기 식별 | 등록 시 발급·보관하는 `deviceUuid` 및 **기기별 API 토큰**(서버는 해시만 저장) | 규칙 동기화·상태 보고 · 무단 도용 완화 |
| 앱 무결성 증거 | Play Integrity 토큰(등록 시에만, 서버 검증 후 재사용 거부) | 정상 Play 설치 기기만 등록 |
| 앱/OS 상태 | 앱 버전, Private DNS 설정 여부·유형, CallScreening 역할 보유 여부 | 보호 저하 감지 |
| 앱 스캔 | 위험으로 판정된 패키지명, 설치 출처 힌트, 권한/오버레이 가능 여부, 위험 점수·사유 | 사기·사이드로드 앱 관리자 보고 |
| 규칙 | 관리자가 설정한 국가 제한·화이트리스트 버전 | 차단 정책 적용 |

## 2. 수집하지 않는 정보

- 전화번호 **원문**의 서버 저장(차단 판단은 기기 로컬)
- SMS/채팅 본문, 사진·마이크·정확한 위치
- 광고 ID 판매·광고 네트워크 공유
- 소셜 로그인 계정

## 3. 처리·보관

- 전송: 운영 환경에서는 **HTTPS** 사용을 전제로 합니다.
- 보관: 관리자가 운영하는 백엔드 DB. 보관 기간은 관리자 정책에 따르며, 기기 삭제·앱 제거 시 관련 행을 삭제할 수 있습니다.
- 접근: 관리자 API 키 / Admin UI 세션. Play 기기는 **기기별 토큰**으로 기기 API만 호출합니다(APK에 장기 공유 키 없음).

## 4. 제3자

- **NextDNS 등 Private DNS**: 관리자가 선택한 DNS 정책 제공자입니다. ElderShield는 DNS 쿼리를 광고 목적으로 판매하지 않습니다.
- 그 외 광고·분석 SDK를 포함하지 않습니다.

## 5. 이용자(부모님) 권리

부모님은 앱을 제거하여 보고를 중단할 수 있습니다.  
관리자(가족 보호 설정자)는 백엔드에서 기기·스캔 기록 삭제를 요청·수행할 수 있습니다.

## 6. 아동

본 제품은 미성년자 대상 서비스가 아니며, 가족 보호 목적의 성인 관리자 통제를 전제로 합니다.
