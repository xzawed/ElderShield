Best under bank-app constraints: Android Private DNS → dedicated NextDNS profile (no VpnService).

  1. Create a dedicated NextDNS profile for ElderShield.
  2. Set NEXTDNS_API_KEY + NEXTDNS_PROFILE_ID on the backend.
  3. Mark restrictions with dns/internet, then Sync.
  4. Phone: Private DNS hostname = PROFILE.dns.nextdns.io.
  5. Enable NextDNS Parental Control → Block bypass methods (DoH).
